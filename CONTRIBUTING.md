# Contributing

## Branches

- `main`: release branch
- `develop`: integration branch
- `feature/*`: feature branches

## Workflow

1. Create `feature/<name>` from `develop`.
2. Commit frequently with clear English messages.
3. Open PR from `feature/*` to `develop`.
4. After validation, merge `develop` into `main`.

## Commit Message Pattern

Use Conventional Commits:

- `feat: ...`
- `fix: ...`
- `docs: ...`
- `test: ...`
- `chore: ...`
- `ci: ...`

## Pull Request Checklist

- Scope is focused and testable.
- Tests updated or added when needed.
- README/docs updated when behavior changes.
- No unrelated file changes.
